How to read this view

Each full-resolution image cell addresses one stored source value. A lower pyramid level averages the selected transformed field over aligned source blocks. Transformation is applied before averaging; opposite signs can cancel in signed rules. Magnitude averages absolute weights, so signs never cancel. Edge blocks contain only actual addresses.

Numerical pooling and screen magnification are separate. Fit-to-screen can hide individual cells even when scalar-level tiles are loaded.

Global rules use the completed checkpoint calibration. Tensor rules enhance local contrast; the same color in another tensor can represent a different number. Exact bounds and formulas above come from the backend.

Vectors keep their native shape: one row, with no wrapping or padded weight cells. Zoom in or enter an address when a fitted vector looks thin.

Patterns in weights or colors alone do not establish learned concepts, circuits, or functional importance.
