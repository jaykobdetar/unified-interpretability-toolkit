# Static inspection evidence and limits

The retained evidence supports the exact scopes below. Evidence receipts and review provenance remain outside the release source tree. Source integration alone does not leave a model enabled or authorize another test.

| Evidence | Recorded scope |
| --- | --- |
| Pure source contracts | Configuration/receipt validation, private binding, closed admission, original-grant publication, leases, cleanup and client gating with inert doubles. The corrected source review reports 203 Python and 25 Node cases passing. |
| Two tiny synthetic native cases | Complete source identity, full native model catalog and public projection correspondence for a single-shard tied BF16 fixture and a sharded untied fixture with BF16/F16/F32 tensors; confirmed owned cleanup. |
| Tiny ordinary lifecycle control | Cold catalog, explicit acquire, shared leases, ordinary idle, release/reopen and three BF16 scalar comparisons. Twelve HTTP requests and six source-oracle bytes. This generic control did not exercise the real Smol admission policy. |
| Pinned real Smol lifecycle | One ordinary static trial for the exact source in DENSE-STATIC-ADMISSION.md, followed by final disable and removal of its owned temporary activation policy. Eighteen HTTP requests, fourteen sealed dense finalizers and nine BF16 comparisons using eighteen source-oracle bytes. |

The real trial bound a complete 272-tensor BF16 catalog with 134,515,008 parameters. Its descriptor has width 576, 30 layers, explicit head dimension 64, nine query heads, three KV heads and tied embeddings. Header/index coverage was complete. No newly hashed shards, streamed calibration values or materialized tiles were reported.

The nine assigned scalar comparisons covered layer-zero Q corners, two layer-29 K addresses, two embedding addresses, and a repeat of the first Q address after reopening. The retained records contain coordinates, offsets, raw bits, classification and passed runtime equality assertions. Review independently validated recorded offsets, BF16 decoding and metadata coherence. Individual native decimal response bodies and a complete chronological HTTP/lease trace were not retained; no broader numerical claim follows.

The real trial retained its 30-second outer limit, 768 MiB native address-space/tree RSS controls and original five-second wall/four-second CPU grants through publication. Reported peak tree RSS was 71,053,312 bytes and minimum available memory was 8,454,520,832 bytes. These observations concern this static trial. There is no independent per-request timing trace or inference fit/performance qualification.

## Final recorded state

The complete final owner receipt equals the original disabled receipt byte for byte. The isolated registry ended at revision 3 with the model disabled. Its temporary activation policy was removed. Retained cleanup records report the reader, streams, listener and owner/watchdog/coordinator threads closed; the process book settled, the supervisor idle, zero snapshot charge and no remaining owned process or cleanup error.

Supporting configuration and proof files were preserved. During-trial readiness metadata is historical evidence, not a statement that a reader is active now. Neither these docs nor integration patches change registration, enablement or local model files.

## Outstanding qualification

The registered picker and raw-inspection form have retained pure client checks but no accepted actual-browser qualification. Color rendering, selected-tensor/global calibration, tile behavior and visual quality remain outside the completed static lifecycle scope. An uncalibrated hosted model exposes raw inspection and states that color scales need separately reviewed owner preparation.

GPU inference at stored precision, measured fit, restoration across edited/cancelled/reset resident inference runs, standardized quantized inference, real small-Qwen family qualification and general production admission remain unqualified. Synthetic Qwen-shaped fixtures are not evidence for real Qwen inference. Static dense BF16/F16/F32 support does not infer packed quantization scales or encodings, enable custom model code, or permit an FP32 fallback.

The smallest proposed browser check is explicit picker selection and repeated raw inspection of one already-qualified Smol address across an ordinary close/reopen. It requires separately reviewed source, a new owner-authorized bounded slot, exact public source/binary bindings and final disable/cleanup. Preparing that proposal is not authorization to execute it.
