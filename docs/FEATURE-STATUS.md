## Qualification context

The following retained results apply to their recorded workloads and source revisions. They do not imply that every optional mode was rerun for a documentation update.

The integrated export/archive workflows passed bounded synthetic browser checks, with independent NumPy decoding of all 18 downloads. Active journal reload, native file permissions and actual inference/archive integration remain unqualified. The worked Qwen key-normalization example verifies a bounded source read.

Legacy dense SVD remains capped at 64×64. The separate 128×128 summary passed the current diagonal128 worker plus independent oracle and the fixed dense-offset standalone HTTP/browser workflow, including observed active owned cancellation. Three additional numeric cases retain their earlier source-lane qualification; they were not rerun on this batch. Registry/fixture-host analytics stays unavailable. Public-model windows, vector/rectangular numerics and whole-model spectra remain unqualified.

Qwen BF16 runtime qualification failed its baseline oracle in a separate trial. GPU/resident runtime and diagnostics remain excluded; acquisition is not inference or GPU readiness. Static model-picker source has portable contract checks, reviewed combined source/reader correspondence and one bounded real Smol picker/raw-inspection browser result. Native tests remain evidence for their recorded source; the naming build and current reader binding have separate provenance. Dense activation still requires the complete current owner policy, receipts and separate approval. Full-tensor profile work remains separate; these source-specific qualification records do not substitute for current-commit CI.

## Checks and unqualified environments

Default unified CI covers pinned formatting, static analysis and strict typing, offline Rust build/test/clippy, syntax, deterministic contracts, and synthetic CLI smoke/launcher checks. Optional real-model, numerical-reference, and browser harnesses remain separate. Long uninterrupted workflows, physical mobile devices, arbitrary checkpoints, low-memory endurance, GPU support and public internet service operation are not claimed. Historical machine-specific qualification receipts are kept privately outside the release tree.
