# Head sweeps and pinned architecture

## Edit and control contracts

`head L H` now edits the architecture-verified **O projection column block** `[H*head_dim,(H+1)*head_dim)`. With zero, this removes that query head's contribution after attention concatenation. Scale is a head-output scaling intervention. `query_head L H` separately edits Q projection rows; legacy `offset L H[,H...] O` is explicitly a query-row offset intervention. A zero query generally creates a nonzero attention-weighted value mixture and is not called head ablation. Inspector shortcuts distinguish output columns from query rows.

The reviewed built-in Transformers 4.56.2 Llama code projects Q/K/V to `[batch,heads,positions,head_dim]`, expands each K/V head contiguously via `repeat_kv`, transposes attended values back to `[batch,positions,query_heads,head_dim]`, flattens the final two dimensions and calls `o_proj`. Therefore query head `h` uses KV `floor(h / (query_heads/kv_heads))`; its output occupies the corresponding O-input columns. For the pin this is nine query heads, three KV heads and dimension 64: Q heads 0–2 share KV 0, 3–5 share KV 1, 6–8 share KV 2. O-column ablation leaves K/V parameters and other heads intact. Runtime verifies exact built-in classes, eager eval execution, bias-free Linear layouts, dimensions, CPU FP32 matrices and storage aliases. Unreviewed versions/layouts fail before inference. See [the shared descriptor contract](HEAD-LAYOUT-CONTRACT.md).

`layer L` expands to all output-head zero ablations for exactly one layer. It is **one worker and one accepted plan**, ordered as empty control followed by each target and its paired control. Pinned SmolLM2 expands to 9 targets + 9 controls + 1 empty case = 19 records / at most 38 prefills for one prompt. Two prompts would require 38 records and are refused before model access because the existing trace cap is 32. Explicit 1–2 target subsets still permit 1–2 prompts, at most 10 records / 20 prefills. No request splits into jobs, silently truncates targets, resumes or retries.

A full-layer control is a deterministically selected different output head with the same shape and operation. Controls are **comparison interventions, not assumed null effects**. They are disjoint from their paired target but necessarily may coincide with another target or control. Each is recomputed from restored weights. Subsets retain global disjointness within the same projection/layer. Algorithm and plan versions advance to v2; old accepted digests fail, forcing review of changed semantics. The plan binds exact prompts, seed, architecture, geometry, operation and control semantics. Prompt-bound digests remain excluded from export without prompt consent.

## Budgets, restoration and coverage

Admission hashing, worker hashing, load and all forwards share the original sweep deadline and remaining CPU grant: 120 wall seconds / 90 CPU seconds total. The OS hard limit remains; an additional between-forward CPU margin reserves 5 CPU seconds and existing 10 wall seconds for cleanup. There is no fresh per-head allowance. A long individual forward may still require worker disposal at the hard deadline; no completion is claimed for an unfinished case.

Each case uses the existing capped 65,536-cell, deduplicated native snapshot mechanism. Output-head ablation selects 36,864 cells. Its indexed snapshot is 144 KiB FP32 plus 288 KiB integer indices, before bounded Python bookkeeping and working temporaries. Restoration occurs in `finally`, verifies original bits including signed zero, and only then emits a completed record. Every later baseline is compared bitwise with the initial original-model logits for that prompt. Any restoration or parity uncertainty fails the worker and retains coordinator ownership until reaping. These checks are not a whole-model pristine proof.

Coverage retains completed/unrun/interrupted record IDs and adds `finished_targets`, `unfinished_targets`, `unfinished_heads`. A target counts as finished only when every requested prompt has both target and matched-control records; an empty control must also complete for the plan to be complete. Unrun work is never assigned a zero effect. Partial completion is a valid reported outcome, not permission for a chained run.

Model dimensions, layer options, head counts, GQA groups, head size, vocabulary bounds, matrix shapes and capture-site options now derive from the SHA-256-checked pinned configuration. The activation grid wraps the returned width for display; it does not infer tensor or head layout. Pinning remains a separate allowlist: synthetic alternate-dimension tests do **not** authorize other models. Existing prompt, generated-token, edit, trace, IPC, session-log, RSS, headroom and browser guards remain.


Cross-session model residency is not implemented. Workers accept one request and are disposed/reaped before replacement. Configuration-derived dimensions do not authorize other checkpoints, GPU execution, or runtime versions.
